# Docs

Project documentation lives here. Suggested starting points:

- `docs/project.md` — purpose, users, scope, and non-goals
- `docs/architecture.md` — how the pieces fit together and why
- `docs/decisions/` — one short record per irreversible choice

Specs and change artifacts do not go here; they live in `openspec/`. Durable
agent conventions live in `.agents/skills/`.
